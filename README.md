# 🎧 Velvet Beats – Music Player

A modern and stylish music player built using HTML, CSS, and JavaScript.

## ✨ Features

- Play and Pause music
- Next and Previous track controls
- Song title and artist display
- Music progress bar
- Volume control
- Interactive playlist
- Automatic next song playback
- Responsive dark luxury UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎨 Design

Velvet Beats features a dark luxury theme with burgundy and rose accents, smooth animations, and a modern interface.

## 📂 Project Structure

Music-Player/
│
├── index.html
├── style.css
└── script.js

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Enjoy listening!
